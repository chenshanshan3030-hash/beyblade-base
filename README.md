# 陀螺對戰基地

給國小低年級孩子的戰鬥陀螺介紹網站（純 HTML/CSS/JS，不需要安裝任何東西）。

- `index.html`：所有分頁（首頁、零件、類型、規則、發射、對戰、家長），用網址 `#` 切換
- `assets/sim.js`：零件資料（自編，非真實商品）＋對戰物理模擬，可用 node 測試
- `assets/app.js`：畫面互動（拆解圖、組裝實驗室、裁判測驗、拉繩練習、對戰遊戲）
- `assets/style.css`：樣式

改了 CSS/JS 後，記得把 `index.html` 裡的 `?v=` 數字加一，避免瀏覽器用舊檔。

本站為家長自製，和戰鬥陀螺官方無關；圖都是自己畫的示意圖。
